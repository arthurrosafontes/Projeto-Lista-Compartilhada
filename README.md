# Projeto-Lista-Compartilhada
Utilizando conceitos aprendidos na Imersão Engenharia de Software: Dev na Era da IA, da Alura, estou desenvolvendo um projeto de uso pessoal para ajudar nas listas de compras. Nele, cada usuário pode criar uma lista, entrar em outras através de convite e adicionar, editar ou remover alimentos.
